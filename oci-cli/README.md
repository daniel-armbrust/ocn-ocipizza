# OCI CLI

Este diretório contém scripts Shell para criação, configuração e gerenciamento de recursos na **Oracle Cloud Infrastructure (OCI)** utilizando a **OCI Command Line Interface (CLI)**.

## Objetivo

Demonstrar o provisionamento de recursos na OCI por meio de comandos CLI, como alternativa ao uso do Terraform no projeto **OCI Pizza**.

## Documentação

Para mais informações sobre a OCI CLI, consulte a [documentação oficial da Oracle](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/cliconcepts.htm).
